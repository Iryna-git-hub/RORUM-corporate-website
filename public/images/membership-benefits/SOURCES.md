# Membership benefit icon sources

The benefit-card assets in this directory are 512 x 512 transparent PNG icons
downloaded from Flaticon for local website use. Each individual asset page was
checked on 2026-07-19 and displayed the Flaticon free licence: personal and
commercial use is permitted with attribution. Attribution is required and is
included in the site footer. The Annual Membership asset is a transparent SVG.

The nine benefit-card icons are authored by Freepik in Flaticon's Special Flat
style. The Annual Membership illustration is a Storyset asset by Freepik in
the Pana style. Storyset permits personal and commercial use with attribution;
the site footer includes the required Freepik attribution.
